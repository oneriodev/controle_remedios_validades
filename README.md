# Controle de Validades Farmacêuticas (MVP)

Sistema de apoio ao controle FEFO de lotes e validades em farmácias:
app mobile coletor (Expo), API (FastAPI + PostgreSQL) e painel gerencial (Streamlit).

> Este sistema apoia o controle de validade e não substitui as obrigações
> sanitárias da farmácia. Não trata medicamentos controlados.
> Todos os dados deste repositório são fictícios.

## Estrutura
- `api/`: backend FastAPI
- `mobile/`: app coletor (Expo)
- `painel/`: painel gerencial (Streamlit)
